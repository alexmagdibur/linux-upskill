# linux-008 — Текстовые фильтры awk и sed

Practice, junior, ~20 мин, 100 XP.

Обработайте CSV и конфиг без текстового редактора: awk для вычислений и выборки, sed для замены.

## Тесты

- `tests/solution.sh` — эталонное решение (должно проходить);
- `tests/wrong.sh` — типичная ошибка (не должно проходить);
- `tests/alt_*.sh` — альтернативные способы решения (должны проходить).
