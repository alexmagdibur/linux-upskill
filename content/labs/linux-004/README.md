# linux-004 — Поиск файлов через find

Practice, junior, ~15 мин, 100 XP.

Найдите нужные файлы по имени и размеру и наведите порядок в дереве проекта командой find.

- `tests/alt_*.sh` — альтернативные способы решения (должны проходить).
