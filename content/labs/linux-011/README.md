# linux-011 — Пользователи и группы (без host privileges)

Practice, junior, ~10 мин, 100 XP.

Исследуйте учётные записи системы: id, getent, /etc/passwd и /etc/group. Создание пользователей в песочнице недоступно.

## Тесты

- `tests/solution.sh` — эталонное решение (должно проходить);
- `tests/wrong.sh` — типичная ошибка (не должно проходить);
- `tests/alt_*.sh` — альтернативные способы решения (должны проходить).
