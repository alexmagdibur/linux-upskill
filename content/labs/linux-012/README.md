# linux-012 — Переменные окружения

Learn, beginner, ~15 мин, 50 XP.

Разберитесь, как переменные окружения передаются дочерним процессам и как сделать PATH постоянным.

## Тесты

- `tests/solution.sh` — эталонное решение (должно проходить);
- `tests/wrong.sh` — типичная ошибка (не должно проходить);
- `tests/alt_*.sh` — альтернативные способы решения (должны проходить).
