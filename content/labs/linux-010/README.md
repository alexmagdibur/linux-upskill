# linux-010 — Владельцы файлов chown (без выдачи опасных прав)

Practice, junior, ~15 мин, 100 XP.

Управляйте группой-владельцем: chown :группа, chgrp -R и setgid-каталог. Смена пользователя-владельца требует root и в песочнице не выдаётся.

## Тесты

- `tests/solution.sh` — эталонное решение (должно проходить);
- `tests/wrong.sh` — типичная ошибка (не должно проходить);
- `tests/alt_*.sh` — альтернативные способы решения (должны проходить).
