# linux-014 — Диагностика дискового пространства (quota/workspace)

Practice, junior, ~15 мин, 100 XP.

Рабочее пространство ограничено по размеру. Найдите, что занимает место, и освободите его, не удалив ценные данные.

## Тесты

- `tests/solution.sh` — эталонное решение (должно проходить);
- `tests/wrong.sh` — типичная ошибка (не должно проходить);
- `tests/alt_*.sh` — альтернативные способы решения (должны проходить).
