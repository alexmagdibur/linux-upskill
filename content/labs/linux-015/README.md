# linux-015 — Bash-скрипт резервного копирования

Practice, middle, ~25 мин, 150 XP.

Напишите настоящий bash-скрипт: аргументы, проверки, код возврата и создание датированного архива.

## Тесты

- `tests/solution.sh` — эталонное решение (должно проходить);
- `tests/wrong.sh` — типичная ошибка (не должно проходить);
- `tests/alt_*.sh` — альтернативные способы решения (должны проходить).
